# 文档智能问答平台：本地演示说明

## 1. 项目用途

本项目用于演示“文档入库—知识检索—问题回答”的完整 RAG 工作流。上传业务资料后，系统会提取文本、切分段落、生成向量并保存到本地知识库；提问时，系统先找到关联段落，再据此组织回答和参考来源。

默认演示模式使用本地哈希向量和本地回答逻辑，因此即使没有模型账号、API Key 或云端数据库，也能体验完整页面与接口流程。

## 2. 技术组成

| 部分 | 技术与职责 |
| --- | --- |
| 后端 | Python、FastAPI；提供上传、集合管理、检索和问答接口 |
| 文档处理 | 支持 Markdown、HTML、DOCX、PDF 等文件的文本提取、清洗与分块 |
| 知识库 | 本地向量存储；演示数据保存在本机运行目录，不提交到仓库 |
| 前端 | 根目录 `frontend/` 的静态页面，调用本机后端接口 |
| 可选模型 | 通过 `.env` 配置兼容接口的模型服务；默认不启用 |

## 3. 运行前准备

- macOS（脚本使用 `.command` 格式）。
- Python 3 与 [uv](https://docs.astral.sh/uv/)；若尚未安装，可执行 `pip install uv`。
- 首次启动需要联网下载 Python 依赖。

无需 MySQL、Redis、Docker、Node.js 或任何外部模型密钥。

## 4. 一键启动与关闭

在 Finder 中双击根目录的 `启动.command`，或在终端进入项目根目录后执行：

```bash
./启动.command
```

脚本会自动完成以下工作：

1. 检查 `8000` 和 `5174` 端口是否可用。
2. 首次运行时执行 `uv sync` 安装 Python 依赖。
3. 启动 FastAPI 后端与静态前端，并将进程号写入 `.run/`。
4. 自动打开浏览器页面。

停止项目时双击 `关闭.command`，或执行：

```bash
./关闭.command
```

关闭脚本会停止本项目启动的前后端进程。运行日志位于 `.run/backend.log` 和 `.run/frontend.log`；该目录属于本机运行数据，不会提交到 Git。

## 5. 访问地址与使用步骤

| 地址 | 用途 |
| --- | --- |
| `http://localhost:5174` | 演示前端 |
| `http://localhost:8000/docs` | 后端 OpenAPI 接口文档 |
| `http://localhost:8000` | 后端服务 |

启动后，按以下顺序演示即可：

1. 打开前端页面并新建或选择知识集合。
2. 上传一份 Markdown、HTML、DOCX 或 PDF 文档。
3. 等待系统完成解析和入库。
4. 输入与文档有关的问题，查看回答及相关来源片段。

## 6. 目录说明

| 路径 | 说明 |
| --- | --- |
| `src/api/` | FastAPI 路由、请求处理和服务装配 |
| `src/parsers/` | 文档解析、清洗、表格处理与文本分块 |
| `src/embeddings/` | 文本向量化实现 |
| `src/retrieval/`、`src/database/` | 本地知识库、检索和结果组织 |
| `src/llm/` | 提示词构造与模型回答适配 |
| `frontend/` | 本地演示前端 |
| `启动.command`、`关闭.command` | 一键启动与停止入口 |

## 7. 切换真实模型（可选）

复制 `.env.example` 为 `.env`，在其中关闭演示模式并填写你自己的模型服务地址、模型名和 API Key。`.env` 已被 Git 忽略，不能也不应提交到仓库。

真实模型调用、计费、限流和回答质量由所接入的服务商负责。用于公开演示时，建议继续保持默认演示模式。
